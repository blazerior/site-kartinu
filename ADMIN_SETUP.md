# Админка — настройка и использование

Веб-форма на GitHub Pages, через которую можно **добавлять и удалять картины**, а также **создавать и удалять целые серии**. Изменения автоматически публикуются на сайт по FTP за 1–2 минуты.

---

## Часть 1. Как это устроено (для понимания)

Вся информация о сериях и картинах хранится в одном файле — `data/paintings.json`.
Страницы сайта (страницы серий, галереи на главной, sitemap) **генерируются из него автоматически**.

1. Вы открываете `https://<username>.github.io/<репо>/admin/`
2. Входите по имени пользователя GitHub + ключу доступа (PAT)
3. Заполняете форму → жмёте кнопку
4. Браузер кладёт фотографию в репозиторий (папка `_uploads/`) и запускает автоматику
5. GitHub Actions на серверах GitHub:
   - `apply_change.py` — вносит изменение в `data/paintings.json`, переименовывает фото
   - `generate.py` — заново собирает из JSON страницы серий, блок галерей на главной, `sitemap.xml`
   - `ftp_deploy.py` — заливает изменённые файлы на хостинг
   - коммитит всё в репозиторий
6. Через 1–2 минуты изменения на сайте

> ⚠ **Важно:** страницы `series-*.html` и блок серий на главной (между
> `<!-- GENERATED:SERIES:START -->` и `<!-- GENERATED:SERIES:END -->`) создаются
> генератором. Ручные правки в них будут перезаписаны при следующем обновлении.
> Данные правятся в `data/paintings.json`, внешний вид — в
> `scripts/admin/templates/*.j2` и `styles.css`.

## Часть 2. Подготовка (один раз)

### Шаг 1. Закоммитить файлы

```bash
cd "D:\1 САЙТЫ\Сайт Картины\ekaterina-lapteva"
git add .github scripts admin data _uploads ADMIN_SETUP.md
git commit -m "Admin tooling v2: JSON + static generation"
git push
```

### Шаг 2. Добавить FTP-пароль в секреты GitHub

1. Репозиторий в браузере → **Settings**
2. Слева: **Secrets and variables → Actions**
3. **New repository secret**:
   - Name: `FTP_PASSWORD`
   - Secret: пароль FTP-пользователя `ekater3com`
4. **Add secret**

Хост/логин/порт уже прописаны в workflow.

### Шаг 3. Включить GitHub Pages

1. **Settings → Pages**
2. **Source**: `Deploy from a branch`, Branch: `main`, Folder: `/ (root)`
3. **Save** — через пару минут появится ссылка `https://<username>.github.io/<репо>/`

Админка будет по адресу: `https://<username>.github.io/<репо>/admin/`

### Шаг 4. Создать ключ доступа (Personal Access Token)

1. Откройте: <https://github.com/settings/personal-access-tokens/new>
2. **Token name**: `lapteva-admin`
3. **Expiration**: `90 days` (или `No expiration`)
4. **Repository access**: `Only select repositories` → выберите репозиторий сайта
5. **Permissions → Repository permissions**:
   - **Contents**: `Read and write` ← обязательно
   - **Actions**: `Read and write` ← обязательно
6. **Generate token** и **сразу скопируйте** — показывается один раз.

Формат: `github_pat_XXXX…` (~80 символов). Храните в менеджере паролей.

## Часть 3. Использование

### Войти

1. **Репозиторий**: `<username>/ekaterina-lapteva`
2. **Имя пользователя GitHub** и **ключ доступа** из шага 4
3. Галочка «Запомнить» — только на своём компьютере

### Добавить работу

Вкладка **«Добавить работу»**: выберите серию, впишите название (без кавычек),
материалы, размер (можно пропустить), год, при желании — рассказ о работе
(появится на странице серии), приложите фото → **Добавить картину**.
Внизу появится журнал — дождитесь строки «✓ Готово».

### Создать серию

Вкладка **«Новая серия»**: название, адрес страницы (заполнится сам латиницей,
можно поправить), материалы, описание (пустая строка = новый абзац), обложка
(большое фото в шапке страницы) → **Создать серию**.
После этого серия появится в списке на вкладке «Добавить работу».

### Удалить

Вкладка **«Удалить»**: выберите серию и картину → **Удалить картину**.
Для удаления серии целиком раскройте «Удалить серию целиком…» внизу —
понадобится вписать название серии для подтверждения. Отменить нельзя.

## Часть 4. Если что-то не работает

### «Не получилось войти»
- Истёк срок ключа → создайте новый (шаг 4)
- Ключу не выданы права `Contents: r/w` или `Actions: r/w`
- Опечатка в адресе репозитория

### Журнал показывает «обновление завершилось с ошибкой»
- Откройте ссылку из журнала (лог Actions) — там видно, какой шаг упал
- Шаг **FTP deploy** → проверьте секрет `FTP_PASSWORD`
- Шаг **Apply change** → в логе будет причина (например, «Painting already exists»)

### Картина добавилась, но на сайте не видна
- Кеш браузера → Ctrl+F5, или откройте в режиме инкогнито
- Проверьте файл на FTP: `/home/e/ekater3com/public_html/images/<Название>.jpg`

### Полный откат
Каждое изменение — отдельный коммит в репозитории:
```bash
git log --oneline          # найдите коммит "Auto: update paintings…"
git revert <hash>
git push
```
После revert следующее изменение через админку пересоберёт и зальёт сайт заново
(или задеплойте файлы на FTP вручную).

## Часть 5. Структура файлов

```
data/paintings.json       ← ЕДИНСТВЕННЫЙ источник данных о сериях и картинах
data/index.json           ← компактный каталог для выпадающих списков (генерируется)

.github/workflows/update-paintings.yml   ← workflow (repository_dispatch)
scripts/admin/
  apply_change.py    ← правит paintings.json (add / remove / add_series / remove_series)
  generate.py        ← JSON → series-*.html, блок на главной, sitemap.xml, index.json
  extract_data.py    ← одноразовый: первоначальная выгрузка данных из HTML (уже выполнен)
  templates/
    series_page.html.j2    ← шаблон страницы серии
    index_series.html.j2   ← шаблон блока серий на главной
admin/
  index.html, style.css, app.js   ← веб-форма (GitHub Pages)
_uploads/            ← временная папка для загружаемых фото
```

Локальная пересборка (если правили paintings.json руками):
```bash
pip install jinja2
python scripts/admin/generate.py
```

## Часть 6. Чего нет (можно дописать позже)

- **Редактирование** данных картины — только удалить и добавить заново
  (или поправить `data/paintings.json` руками + `generate.py`).
- **EN-переводы** новых картин и серий не создаются (показывается русский текст).
- **Несколько ракурсов** у новой работы через форму не добавить
  (в JSON поле `images` — массив, руками можно).
- **Изменение порядка** — новая картина всегда в конец, новая серия в конец списка.
